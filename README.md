# stitchdock

Stitch CSV/TSV dock tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/stitchdock/

## Install / run

```bash
git clone https://github.com/theworker02/stitchdock.git
cd stitchdock
node src/cli.js
node --test
```
